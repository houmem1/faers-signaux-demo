# Signaux FAERS – démo

Site de démonstration : https://houmem1.github.io/faers-signaux-demo/

Exploration de signaux de pharmacovigilance par disproportionnalité (PRR, ROR,
composante d'information bayésienne) dans la base FAERS de la FDA, à partir des
données publiques [openFDA](https://open.fda.gov/apis/drug/event/).

Un signal est une hypothèse : il ne mesure ni un risque ni une causalité.
Outil d'exploration, sans valeur de recommandation médicale.
